# AI setup by named values — 12 September 2026

This increment adds `settings`, `configure`, `validate-setup`,
`setup-capabilities` and fixed-path `read-protocol` to the AI CLI. It uses fresh
profile-checked settings after each ordinary panel gesture. The existing Hantek
Studio 0.2 interface remains relative. No provider integration, desktop setup
form, full settings-blob write or waveform acquisition was added.

The owner authorized ordinary scope control while working remotely. The scope
was the same DSO5102P and Windows 11 x64 WinUSB connection as the earlier
sessions. This is USB/settings/display verification, not physical bench or
measurement-accuracy validation. Evidence names use UTC, so the late-session
files begin `20260911T17...` while the local Bangkok date is 12 September.
